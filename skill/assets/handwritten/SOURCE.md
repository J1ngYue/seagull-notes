# Handwritten notebook assets

The ruled paper, margin line, spiral holes, tape, paperclip, folded corner,
leather cover, metal rings and page-turn styling in `../experiences.css` are
adapted from UncleCheng's MIT-licensed **note-skill** templates:

- https://github.com/Unclecheng-li/note-skill
- Upstream revision: `f977c50687019888e70da7ff3053830598cd3c5c`
- Upstream license: `LICENSE-note-skill.txt`

Seagull Notes keeps its own source ingestion, full note body, shelf, navigation,
code/formula copying and accessible interactions. Long chapters grow normally;
content is not cut to a fixed cover height. Paper remains the existing reader.
The legacy `atlas` / `folio` values now select Study Notebook / Leather Journal.

Ma Shan Zheng is bundled for offline Chinese handwriting. The WOFF2 file is
a format conversion of the official regular font, without deleting glyphs:

- https://github.com/google/fonts/tree/main/ofl/mashanzheng
- Original: `MaShanZheng-Regular.ttf`
- License: `OFL-MaShanZheng.txt`

Generated HTML includes the font and both notices, so it can be read offline.
