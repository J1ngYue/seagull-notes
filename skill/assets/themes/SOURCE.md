# Reading theme artwork

`whale-girl.webp` is a newly generated chibi learning illustration inspired by the community DeepSeek whale-girl / 蓝色大肥鱼 design: round face, blue/periwinkle hair, fin ears, navy maid outfit, white whale apron and curled tail. It is not a DeepSeek official character asset.

Generated with the built-in imagegen tool on 2026-10-15. Character reference was inspected before generation; the original meme image is not redistributed in this skill.

References: [community character overview](https://aigengtu.com/zh/whale-chan), [community pet design description](https://github.com/YunYueSama/codex-deepseek-pet), [reference meme](https://imgheybox.max-c.com/bbs/2026/07/31/1d25fd53a23df843f52209cbb83ff214/thumb.jpeg).

Prompt: Preserve the recognizable short, rounded chibi whale-girl proportions, round face, blue eyes, blue/periwinkle hair, curled ahoge, whale-fin ears, white frilly maid headband, navy long-sleeved dress and white whale apron. Draw a new wholesome full-body studying pose with an ivory notebook and pen, curled whale tail, and a small rice bowl beside her. Crisp anime linework and cel shading, navy/white/periwinkle palette, fully clothed, complete padded silhouette, genuinely transparent background. No text, speech bubbles, pointing hand, watermark, scenery or background glow. Do not substitute a realistic-proportioned generic blue-haired woman.

The whale-girl illustration is embedded into generated HTML so the theme works offline. Ocean routes and the light node canvas use native SVG/CSS rather than third-party image assets.

`whale-explain.webp`, `whale-think.webp`, and `whale-celebrate.webp` are transparent poses generated with built-in imagegen on 2026-10-15 using the original whale art, preserving the same round chibi character and outfit. The poses explain with a notebook, study thoughtfully, and celebrate with a small star. No text or scenery.

## Screenshot recreations (2026-10-16)

The user supplied the Ryo Japanese-journal, Moonlight Glass and Pixel Desktop screenshots and explicitly requested recreations. The UI is implemented with HTML, CSS and JavaScript; a screenshot is never substituted for a functional application.

`journal-reference.webp` and `journal-banner.webp` are WebP encodings of the supplied journal-reader and journal-home screenshots, without redraw or resizing. CSS crops only the decorative Ryo photograph, landscape and sidebar artwork. Their original application controls are not used as working controls.

`moon-wallpaper.webp` and `pixel-wallpaper.webp` were edited with the built-in imagegen tool from the supplied moonlight-reader and pixel-shelf screenshots. Prompt set: “Extract the exact illustrated wallpaper; remove all application windows, controls and text; preserve the existing blue-haired Yamada Ryo, pose, outfit, palette and room; continue the background behind removed UI; do not redesign the character or add characters.” These are edited background reconstructions, not untouched official animation images. Final files are WebP without resizing. All backgrounds are embedded for offline reading.

`journal-flowers.webp` is a transparent blue forget-me-not sticker edited with built-in imagegen on 2026-10-16 from the user's scrapbook screenshot.
