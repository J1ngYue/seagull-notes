# 排查

| 现象 | 下一步 |
|---|---|
| `browser_required` / 412 / 机器人验证 / 空字幕列表 | 打开原视频，按 [浏览器流程](browser-subtitles.md) 检查登录、验证和完整字幕。不要直接断言无字幕。 |
| 登录后仍无字幕 | 区分真实无字幕、权限/地区限制、风控，以及仅能显示 CC 而不能导出全文。说明实际障碍。 |
| `file_not_found` / 配图文件不存在 | 检查真实绝对路径；配图相对路径以 note.json 目录为基准。 |
| `empty_subtitle` | 检查原文件是否为空或格式不支持；不要用空文件生成笔记。 |
| 只有视频简介或 AI 总结 | 这不是完整字幕。继续获取全文，或说明无法取得。 |
| `has_more: true` | 按 `next_offset` 继续读，直至全文结束。 |
| `ModuleNotFoundError` | 使用 Anaconda 绝对解释器，按 [setup.md](setup.md) 安装实际缺失依赖。 |
| 未显示视频时间 | 未取得时间轴时保持缺失；不能猜章节开始时间。 |
| 图片只有封面 | 补充有用的课件、图表或演示画面；拿不到时用明确标注的字幕示意图。 |
| `model_missing` / CUDA 错误 | 属于显式开启的 ASR 路径；不影响默认平台字幕流程。 |

一个修正动作后验证一次；相同障碍重复出现且没有新线索时停下并报告，不循环登录、重试下载或要求用户关闭日常浏览器。
