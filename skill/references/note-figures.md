# 笔记配图规范

目标是准确、可读、完整显示。保持暖白背景、深绿曲线和棕色更新标记，与笔记页面一致；不要为追求好看改变数据。

## 数值曲线和更新过程

1. 明确横纵轴含义、单位、公式和数据来源。字幕没有给出的函数或数值必须标为教学示例。
2. 从公式采样或原始数据取得 `x/y`，更新点从同一公式计算。不要用手工 SVG 像素坐标代替数值计算，不静默删除缺失值。
3. 图中只保留少量重点步号，数值放在下方对照；箭头从上一步指向下一步，刻度保持真实尺度。
4. 通过标准绘图库处理坐标、箭头、字体和留白。导出后检查完整图与笔记实际显示，不能只看 JSON 或 SVG 源码。

安装可选依赖 `pip install -e ".[plots]"`，使用：

```powershell
& 'D:\software\Anaconda\python.exe' '<skill目录>\scripts\plot.py' '<配图数据.json>' --out '<图片基名>'
```

输入必需字段：`title/x_label/y_label/x/y`。可选：`subtitle/note/steps`。`steps` 是按更新顺序排列的 `{x, y}` 数组，每图最多突出 5 个点；步号由顺序生成。完整示例见仓库 `examples/gradient-plot.json`。生成器只画传入的数据，不从字幕推断或编造数值，也不执行字符串公式。

输出 SVG 和 1500 × 1080 PNG。SVG 的文字保存为轮廓，离线显示无需目标电脑安装相同字体。生成时需要可用的中文字体，例如 Microsoft YaHei、Noto Sans CJK SC 或 SimHei；缺字或布局错误需修正后重新导出。脚本会拒绝已检测到的文字裁切或重叠，但仍需视觉检查。

## 流程图、概念图和截图

- 流程图与概念图可使用 SVG，但优先短标签和规则排列，文字与箭头留出足够间隔；没有数据依据时不添加看似精确的刻度或数值。
- 真实截图保留原内容，注明时间和来源。解释图明确说明“根据字幕绘制的示意图”，不能冒充视频画面。
- 示意图以 `kind: "diagram"` 填入笔记的 `cover/image`，SVG 默认也视为示意图；保持原比例，不用裁切方式填满封面。
- 页面中的配图可点击查看大图；窄屏检查全部文字、坐标和图注，不让缩小后的图片成为唯一阅读方式。
