# README artwork and screenshots

The English and Chinese READMEs use separate image sets. The SVG hero and workflow diagrams were authored for this project; the book in the hero is a product overview illustration, not a screenshot.

`readers-en.webp` and `readers-zh.webp` combine real Paper, Leather Book, Ocean Voyage, and Pixel Desktop renderer output. Each viewport was 1440 × 1000 CSS pixels, captured at device scale factor 2. The composite preserves each 2880 × 2000 screenshot without enlarging or shrinking it.

- Chinese preview source: [`../knowledge.json`](../knowledge.json), using the existing Chinese lesson and interface.
- English preview source: [`preview-en.json`](preview-en.json), an English adaptation of the Git example with the same official references. Interface labels were translated in an isolated documentation browser page; application templates and the installed skill were not localized. The English book preview uses the existing sans-serif font option.
- These previews were rendered without adding documentation examples to the user's notebook shelf. Screenshots show generated teaching examples, not the processing of a particular video.
- Embedded whale and pixel artwork retains the provenance and rights described in [`../../skill/assets/themes/SOURCE.md`](../../skill/assets/themes/SOURCE.md). Handwritten / leather assets retain their [original notices](../../skill/assets/handwritten/SOURCE.md).
